# Phase 6 realtime AI validation

This validation covers the local synthetic recorded inputs only. It is not a
formal accuracy benchmark or a claim about deployment CCTV performance.

## Runtime architecture

- The decoder follows the source timestamp and publishes a bounded latest-frame
  buffer.
- YOLO11n + persistent ByteTrack consumes the newest available frame. Stale
  detector frames are dropped; they are never queued behind live playback.
- Recent track velocity is used to predict a box for at most 350 ms. Older
  boxes are removed rather than displayed indefinitely.
- The viewer reports current-frame counts separately from observed-window unique
  track counts.
- Optional `SURAKSH_ROI_JSON` supplies `[x1,y1,x2,y2]` per camera for road-only
  inference. Coordinates are translated back to full-frame space.

## Measured local performance

| Source | Source FPS | Viewer FPS | Detector FPS | Inference | Device |
|---|---:|---:|---:|---:|---|
| VMS-A | 25.0 | 20.6 | 1.6 | 422 ms | CPU |
| VMS-B | 23.976 | 23.4 | 2.4 | 281 ms | CPU |

The detector is configured for a 5 FPS target, but CPU saturation limits the
measured effective rate. Playback remains near native speed because detector
latency does not block frame ingestion.

## Model/input benchmark

Generated by `scripts/phase6_benchmark.py` and stored at
`.runtime/phase6/benchmark.json`. CUDA was unavailable and `yolo11s.pt` was
not present locally, so no model switch was made. The installed yolo11n model
was benchmarked at 640, 768, and 960 input sizes. The viewer continues using
the measured safe configuration and does not claim yolo11s accuracy.

## Multi-frame ANPR

`scripts/phase6_multiframe_anpr.py` runs genuine Tesseract over six selected
frames and two preprocessing variants for each validated target track. It does
not insert the expected plate into OCR output.

- VMS-A target track 403: consensus `GJ01AB1234`, 12 OCR attempts.
- VMS-B target track 14: consensus `GJ01AB1234`, 12 OCR attempts.
- All accepted candidates remain associated with their source target track.
- No trained local plate detector is available; the explicit white-rectangle
  detector is retained as a synthetic-test fallback only.

Evidence: `.runtime/phase6/anpr/consensus-report.json`.

## Accuracy review boundary

The existing synthetic clips demonstrate detection, tracking, vehicle classes,
and ANPR behavior. A formal 20-frame manually labelled precision/recall set
has not been asserted here; real deployment accuracy still requires a rights-
approved, camera-diverse labelled dataset with manual people/vehicle/type
counts and fast-vehicle misses recorded independently of YOLO output.
