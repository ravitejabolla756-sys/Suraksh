# Suraksh ANPR Evaluation

Use an approved annotated ANPR dataset and report plate detection precision,
recall, F1, AP50/AP50:95, OCR exact/normalized accuracy, character accuracy,
CER, vehicle↔plate association accuracy, and single-frame versus temporal
consensus accuracy. Stratify day/night, distance, angle, blur, glare, weather,
and plate size. Report latency and sample rate. No metrics are claimed until
the annotated evaluation is complete.
